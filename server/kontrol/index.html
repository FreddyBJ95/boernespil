Tabletten kan ikke komme ind?

Kontrollerer computerens netværk…

Vis hjælp til wifi og firewall
  1. Computer og tablet skal være på samme hjemmenetværk. Undgå gæstenetværk, der kan holde enheder adskilt.
  2. På Windows: Åbn Indstillinger → Netværk og internet → Wi-Fi (eller Ethernet), vælg hjemmets forbindelse og vælg Privat. Gør kun et netværk privat, hvis du kender og stoler på det.
  3. Søg efter Tillad en app gennem Windows Defender Firewall. Vælg Rediger indstillinger → Tillad en anden app → Gennemse, vælg den BroekraftServer.exe, du starter, og sæt flueben ved Privat.
  4. Genstart serveren, og scan den nye QR-kode. Hvis siden åbner, men viser certifikatfejl, følg certifikattrinnet nedenfor.

Netværkstjekket opdateres cirka hvert minut. Det kan ikke afgøre, om firewallen tillader forbindelsen. På Mac kontrolleres appens adgang under Systemindstillinger → Netværk → Firewall. Routerens porte skal ikke åbnes.

🎤 Gør tabletten klar til mikrofon

En voksen gør dette én gang, før spillets nye HTTPS-adresse åbnes.

  1. Scan certifikatkoden i Safari, og hent profilen.
  2. Indstillinger → Profil hentet → Installer.
  3. Indstillinger → Generelt → Om → Certifikattillid: slå tillid til Broekraft Server hjemme til.

Installer kun certifikatet fra jeres egen computer. Aftrykket på tabletten skal være det samme som her:

📱 Forbind tabletterne

  1. Tabletten skal være på samme wifi som denne computer.
  2. Scan QR-koden med tablettens kamera — eller skriv adressen.
  3. Tryk Del → Føj til hjemmeskærm, så har barnet et "Broekraft Sammen"-ikon.
